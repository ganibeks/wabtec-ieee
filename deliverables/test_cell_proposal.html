IGBT Bench Test Cell

A bench that checks a traction IGBT module before it goes on a locomotive, gives a PASS / NO-PASS result and writes a report to a laptop. This page answers the four questions on slide 11: which parameters, how long, how to run it, and what it costs.

Desaturation: the module is switched on into a short at 1800 V (the shoot-through case on slide 8). The slide 8 notes count the 10 µs from fault detection. The simulated DESAT circuit detects the fault 7.6 µs after gate-on and pulls the gate below threshold 1.9 µs later. The collector current then falls slowly because the model's turn-off tail is far too long (see section 6), so it is below 10 % only 24.4 µs after detection. The 17.4 kA peak short-circuit current is a model value and is not validated.

Driver power: 0.223 mJ per switching cycle. The slides give no switching frequency, so 1 kHz is assumed (typical upper end for 3.3 kV traction IGBTs); 20 W would only be reached at about 90 kHz. Driver quiescent losses are not included. The diode forward value passes because the model's diode knee was set inside the slide range; it shows the test logic works, not that a real diode is good. Busbar insulation is a hardware-only check and is not part of the simulated verdict.

2How long a check takes

Benchmark: today about 3.5 minutes per IGBT with the module connected to the tester, giving PASS / NO-PASS (Wabtec instruction IM-LE-0008, step 14). A locomotive has 36 modules, one switch each (6 inverters × 3 phases × 2). The electrical tests themselves last microseconds to milliseconds; the connected time goes into the insulation dwell and into charging and discharging the DC link safely.

Why this is enough. In 2.2 minutes the cell covers every slide 5/8 parameter, including the module at 1800 V and about 1.5 kA and the desaturation protection. A module that passes low-voltage checks can still fail at working voltage; finding that on the bench costs seconds, finding it on the locomotive costs an installation and removal.

Where time can still be cut. The 60 s insulation dwell is the longest step. It can be run on a sample basis or in a separate station, which brings the connected time to about 1 minute. A thermal cycling or burn-in test would take hours per module, so we suggest it only for modules returned from service.

3Test instructions

High voltage. The DC link is charged to 1800 V and stores lethal energy. Only trained staff run the cell. The enclosure door is interlocked: opening it removes the charger and closes the discharge relay.
  1. Prepare the cellonce per shiftCheck the e-stop, door interlock and discharge relay. Run the self-test with the reference module and confirm it passes.
  2. Register the module2 minScan the serial on the laptop. Inspect for cracks, discoloured terminals and damaged gate connectors. Reject on visible damage.
  3. Mount the module5 minPlace it on the fixture. Torque the power terminals to the module manufacturer's value. Connect gate leads and the fiber-optic command link. Close the door.
  4. Run the low-voltage block30 sPress START. The cell measures the diode forward and reverse values, the gate drive levels and the gate threshold. Any value outside the slide range stops the sequence with NO-PASS.
  5. Run the insulation test70 sThe cell ramps the hipot voltage between busbar and heatsink, holds it for 60 s and records leakage. Limit: 2 mA (slide 5).
  6. Run the high-voltage block25 sThe cell charges the DC link to 1800 V, runs a double pulse (gate ±15 V, peak di/dt limit 5000 A/µs), then one DESAT trip (turn-off within 10 µs of detection) and discharges the link.
  7. Read the result5 sThe door unlocks once the panel shows DC link < 50 V. The laptop shows PASS or NO-PASS with every measured value and saves a PDF/CSV report under the serial number.
  8. Release or quarantine—PASS: label and release for installation. NO-PASS: tag red, attach the report, send for failure analysis.

4Cell architecture

Laptop (report, PASS/NO-PASS) ──USB── STM32G474 controller ──fiber── gate drivers (±15 V, DESAT) │ │ relay matrix, ADC, interlocks phase module on fixture │ │ HV charger 0–2.5 kV → DC-link capacitors → laminated busbar → load inductor 300 µH │ Rogowski coil + HV differential probe → fast digitiser (≥ 100 MS/s)

The STM32G474 runs the test sequence, interlocks and DESAT supervision. Its 12-bit ADC is too slow to resolve sub-microsecond edges, so di/dt and switching times come from the separate fast digitiser. The tester firmware is written in C++ and already runs in simulation against the MATLAB waveforms.

6What the simulation shows, and what it does not

Every simulated value on this page comes from MATLAB R2026b / Simscape runs that passed their own numerical checks: no solver warnings, energy balance within 6 × 10−7, and results unchanged within 3 % when the time step is halved. Run folder: results/dynamic_20261017_195453_347.

  • The device is a representative CM1500HC-66XB built from its datasheet. It is not a confirmed Wabtec part, and no Wabtec acceptance limits were used beyond the values on slides 5 and 8.
  • The model's current tail at turn-off is far too slow: fall time 21.9 µs against the datasheet maximum of 0.70 µs. Three attempts to calibrate it stopped the solver, so it is recorded as a known limitation. Turn-off energy is overestimated, and the simulated desaturation turn-off misses 10 µs because of it.
  • Desaturation run: results/desat_test_traction_20261017_212553_145, no solver warnings, half-step change 0.04 %. Detection settings (9 V threshold, 7.5 µs blanking) are assumed.
  • The free-wheeling diode has no reverse recovery, so turn-on overshoot is underestimated.
  • Insulation cannot be simulated honestly; it needs the hipot measurement on hardware.
  • The hardware decision stays inconclusive until the cell measures real modules.
